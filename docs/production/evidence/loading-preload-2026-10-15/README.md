## 实际实现

初始 HTML 内置纸面山河、日印与三张扑克牌构图，JS 到达前已可见。Boot 先准备原 P00 纸桌，再复用 `ArtTextureLoading` 的共享请求/已解码 Phaser 缓存和 `ImageWarmupQueue`；没有另造图像传输管线。常用起手牌排在其余缩略图前，正式人物资产注册表当前为空，不产生英雄图片请求。134 项为 8 纸桌 + 3 人头牌 + 72 唐宋牌缩略图 + 51 工具/道具缩略图，预计 RGBA 13.6328125 MiB，目录预算 16 MiB；这不是进程总内存或 GPU 实测峰值。高清详情仍走原独立小缓存，不加入开场门禁；音乐和移动端用户手势限制未改。

进度只计完成解码并发布的纹理，失败不计成功。两条准备任务、共享传输限额/字节上限/解码守卫沿用；批次 12 秒期限后给出重试/文字继续，加载中也可主动文字进入。用户明确降级的键在本次游戏内免重复门禁，现有场景卡面恢复入口保留。转场门禁按实际持牌、现货和保存来源读取，不预生成未来商店、抽牌或 RNG；商店/结算提前请求下一场景。过期转场和 game destroy 取消本批所有权，旧回调不再导航。冷恢复也经过同一准备入口。详情缩略图解码完成前隐藏，关闭后的迟到回调不重新展示。

按用户要求仅删除 `public/assets/cast-placeholders/` 中 18 张姓名 SVG 和 manifest；选角、比较、英雄说明、头像、回看留影都以文字展示。旧正式资源、来源记录、历史证据保持；旧戏班脸不作为新六英雄显示。六正式人物立绘/独立眼图仍未交付。

## 原始失败与校正

`raw/type-first-FAIL.txt` 和 `raw/full-tests-first.txt` 保留删除占位后的旧路径/同步场景桩假设失败；测试改为无未审核图片、异步资源准备，并继续断言原规则事实。第二轮仅详情 DOM 桩缺少 decode 方法失败（raw/full-tests-final.txt）；补齐真实解码行为的桩，并新增解码前隐藏/关闭后迟到保护断言。

浏览器首次 320 连续输入未确认已选路线而超时，保留原报告/PNG；样板改为逐步等待真实 step/selectedRoute，并保留 150ms 输入间隔，产品输入规则未改，不签快速连点健壮性。第二轮把用户点击“重试”后合法启动的音频误当成手势前请求，已把检查移到首次手势前，AudioEngine 不改。第三轮在 Vite 运行中编辑源文件造成热重载，原 FAIL 保留；最终固定提交、clean 工作区执行，五组及补充缺 Q 全部 PASS。没有用旧绿报告或删失败签当前版本。
