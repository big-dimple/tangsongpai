## 刘娥：实际加倍率，不当作固定乘倍

普通点数p从热度移到倍率。在无后续钩子的同一时点，差额为p(H−M−p)，不是恒定×p；已有倍率高时相对增益会变小，极端情况下可以不选。实际表格全部调用真实scoreR2Hand，包含后续唐宋牌、成长与最终取整：例如中期已有≥20金×1.8，+8倍率最终被后续乘法放大成+14.4，不能直接用最终M再加8计算。
