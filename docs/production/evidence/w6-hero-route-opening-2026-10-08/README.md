## 原失败解释

`first-driver-assumption-FAIL.log`错误要求每次返回英雄后路线必须清空；实际保留草稿是预期行为，修正测试观察。两次未冻结WIP运行中改源码导致Vite重载：一个等待原图Timeout、一个明确Execution context destroyed；前者原因不能仅凭时序断定，保原日志，冻结运行没有复现。

两个恢复Timeout等待“确认开始新局”。诊断明确：取消候选后原确认弹窗仍开，脚本误点其下画布位置，实际点到了弹窗取消，故没有新弹窗。400ms间隔并不能修复错误目标。最终脚本先用原生DOM取消回路线，再按现有350ms同点防误触保护间隔发起新确认；生产modal保护/测试超时未放宽。旧提示更新是独立真实UI小修。原日志保留，未把驱动错误冒充计分或保存领域失败。
