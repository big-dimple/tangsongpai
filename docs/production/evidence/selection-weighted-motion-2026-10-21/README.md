## 实际变化

- A 纸上灵尘：沿用已有外围前后分层、疏密漂移和轻微闪光，本轮未更改。保持 32/64 节点池与 30/60Hz 名义更新上限。无需靠增加点数解决蓄力节奏。
- B 游龙墨痕：方头逐段描线改为连续填充的变宽轮廓，三条顺笔方向的干笔裂隙；有指向的尖锋、金墨细边和原有少量断尾。820ms，自然散去。六英雄共用，不新增素材。
- 路线预览：460ms 卡片底部朱砂落笔与收笔短竖，不播放“定”印、不创建局。重复同一路线不重播，减少动态时保留原选中边框与文字。
- C 朱印定魂：1450ms。前约400ms按钮缓慢压至58%高度、88%宽度；随后离地22px（短按钮15px），保持约58ms后在约87ms内加速砸下；着地压至60%高度并停约80ms，再复位。击中点与印记同步。命中矩形不动。
- 收束先出现，浅纸衬底不再提前抢画面；约718ms开始落印，约783ms到峰值，约885ms开始十道金色外迸，约1218ms进入尾衰减。印记略收小以给外迸留出空间。保留局部柔光，不整屏变暗。仍借用现有池。
- 第二次点击/Enter仅请求跳过呈现，落击复位后最早约1015ms结束；不再次保存或创建局。减少动态使用260ms静态印记，没有跳砸。

## 验证与限制

类型检查、22项相关测试、构建通过（build.txt保留既有大chunk警告）。本地Chromium原生鼠标/触屏输入的10项针对性检查通过：六人快速切换/取消、切换失焦、英雄确认与路线预览不建局（含路线重复/失焦）、确认中失焦/缩放/退出/切换减少动态/重复点击、初始减少动态、保存失败不确认。原确认Promise均只完成一次，视觉恢复，事件/借用节点无残留，重复点击不多建局。

两尺寸自然结束录像均检验固定命中框、按钮不出屏、不与其他文字相交，金粒/印记避开面部和文字。非常短横屏只覆盖直接几何测试，未录物理设备。

首次录像与构建/另一浏览器并发，桌面确认帧间隔p95达到162ms；完整保留在 recording-under-load。之后停并发，仅重录两尺寸原速展示，未再改代码，也未重跑矩阵。单独录制的390/1366确认帧间隔p95约17.3/31.6ms，确认时长约1433/1448ms；待机paint p95约0.2/0.3ms。连续轮廓的峰值Graphics命令数2532（上一版732）；短暂绘制复杂度上升，结果不是物理设备性能认证。录制含浏览器采样/截图开销。

未跑全量测试/全局布局矩阵、真机、音频、部署站。旧布局脚本在基线也失败的根因仍未知，本轮不归因或修复。保留工程与审美边界：本轮提供更大的按钮压缩/离地幅度和分离阶段供原速复核，不替用户签收重量感、商业级观感或整体游戏完成。父线程复核后再决定集成；本轮不合main。
