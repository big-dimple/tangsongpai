## 最终规则

**苏轼：普通整数得分×3，每场一次；实际弃掉的余牌中至少有一张当前点数为K的牌。** 主手里的K不算。没有额外金币、弃牌机会、出牌机会或过关奖励惩罚。无K时明确提示“余牌中需有K”；选用/取消不改存档，成功出牌才消费次数。全部实际余牌仍按真实discardedIds走原逐牌切斩/粒子来源，本批没有改动这些表现函数、音频或素材。

条件在真实PlayHand、领域计分器、公用选择事实与checkpoint验证中落地；按当前card.rank识别，不解析技术ID。主手选走唯一K后，原草稿失效。AI只保留能实际弃K的候选；同时修正GameScene构造AI输入时遗漏profile字段的问题，现在完整传递r2ScoreContext，避免沿用旧×4或旧支付价格。

**花蕊：3／6／10金→×1.5／2／3，每场一次。** 保留两对及以上、确认出牌真扣钱、不足不降档、持币效果读扣后余额、奖励前每5金额外1金且最多2金。没有采用此前2/4/6等更低草案。3金小档能较常使用；6/10金仍要求留钱，不能宣传每场最高档。

新局身份：苏轼`quality-r2-amo-exile-v3` / `json-fnv-v1:cf857ebc71020ca8`；花蕊`quality-r2-xiemu-burn-v3` / `json-fnv-v1:a4a83168b2cc5664`。旧v1/v2保存与同局重试保原身份，不迁移、不改技术ID或存档键。其余四英雄、关卡目标、商店基础价格和经济公式不改。

## K门槛的实际含义

标准52张含4K、初抓8张，至少见到一张K的概率为49.86%。**见到K不等于能发动**：主手可能需要这张K，必须将K留在真正舍弃部分。例如双K两对中的K都打进主手，若余牌没有另一张K就不能用。

在固定五张非K主手、余下三张从剩余47张均匀抽取的条件模型里，余牌含K约23.89%；主手已含一张K时约18.32%。这些只是明确条件下的静态概率，不是选牌策略、整场发动率或胜率。普通弃/补牌会改变机会；删牌/改点改变K密度和剩余牌数，染色不改变K数量，但可能让K更有必要进入同花主手。不能把标准牌堆数字推广到构筑后。

## 三场真实现金预算

输入、每步真实余额与收据见[three-stage-budgets.json](three-stage-budgets.json)。每条流执行三场D0实际领域指令，每场先实际BuyOffer一张4或6金、再两次真实出牌过关。货架和牌序是受控夹具，只固定“两手过关”以核算现金，**不是自然货架/成型概率或通关率**。不够钱则该次购买或技能不执行，不借钱、不自动降档。20金是受控已有本金，不是开局赠送。

真实奖励公式未改：暖/正/压轴基础4/5/7金，加剩余出牌机会与普通利息；花蕊再加`min(2,floor(奖励前余额/5))`。实际暖场两手过关、结算前余钱0/5/10金时，花蕊收入6/8/10金，其他无经济来源英雄为6/7/8金。技能消费和购买会压低这笔本金。

这支持选择3/6/10：普通购牌预算下低档可较常发动，最高档需要经营，并非把×3变成免费常驻。初始6金若要第一场付3金，就不能同时全价买4金牌；坚持每场买6金牌，前期连低档也无法保证。保留这种明确取舍，避免为了追平有K时的苏轼而盲目下调。

相同“两手过关、每场买4金牌、6金本金”的受控流中，其他四英雄结束余额都是8→11→17，技能没有金币支付；苏轼被刻意提供可弃K时也是该余额。后者只是可发动分支，不能当成自然三场都能找到可弃K。花蕊留手与额外利息有价值；无留手价值且苏轼恰可弃K时，花蕊同×3仍较贵，这是局部差异，不代表全局严格支配。秦琼常态收益、辛弃疾择牌、刘娥普通点数转倍率、文成高层×4仍各保独立条件，本轮没有改造它们。
