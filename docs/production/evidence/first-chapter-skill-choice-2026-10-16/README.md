## 先复现，再修复

原claim默认读取firstChapterGuide(run)是否当前可见。玩家仅选择“略过此提示”，该手牌行内提示就变为不可见，连带使仍具备技能资格的提醒失效。新增回归用例在原产品上16通过/1失败；普通刘娥新局种子skill-choice-natural-0、普通D0、group路线，自然摸到对子，实际点击“怎么凑牌→略过此提示→关闭→出牌”，也复现提醒缺失。此自然案例没有导入手牌、改金币或手动登记偏好。before图与baseline报告保留，baseline的PASS只表示成功复现缺口。

现在提醒依据原有“本局已登记”状态，单条提示略过只影响它自己。“本局不提示”“不再显示”与提醒自己的“不再提醒”仍尊重。原首两场各一次/每局最多两次、取消或Escape也占本场额度的政策保持。

弹窗明确写“主动操作”，从实际局身份读取英雄/技能名与原资格说明；“继续出牌”只跳过这项主动操作，被动/自动效果仍按各自条件判定。返回仍只是查看选择，不自动选目标/档位或发动；保持原按钮标签以兼容已有操作链。新增长说明由一个正文滚动区承载，原生操作按钮保持可达。
