# 启动加载自动恢复 · Windows 本地证据

基线 `fa5b30ee1ebf28d4ee71d676b231eab260172033`，开发分支 `fix/loading-auto-recovery-20261016`，独立 worktree。本包只修改图片准备、加载视图和生命周期保护；英雄布局、具体文案、机制/数值、存档与素材保持基线。P08 继续 `in_progress`，不合 main，不部署，不查询 CI 或域名。

## 行为

- 缺图不再等待用户点击或带空图进入。初次尝试后，临时失败按 0.5 / 1.5 / 3.5 秒退避；随后每 30–60 秒恢复。单独的永久 404 直接走低频探测。每个准备 owner 只有一轮请求或一个等待；重复 online 事件不创建额外轮次。
- 离线取消本轮未完成请求，等待真实 online 后自动继续。已有解码纹理直接计入完成，后续轮次只请求缺项；整批截止后优先未尝试的队尾，避免坏资源阻塞后续资源。原准备队列、共享纹理传输/内存预算和单文件限制保留。
- 进度条是单调的平滑视觉估计，真实“已解码 n / 146”另列；未满足真实就绪条件时最高 96%，只有全部必需资源已解码才允许完成和进场。减少动态偏好采用真实计数的直接变化，隐藏页面暂停装饰动画；没有同步等待或高频重试循环。
- Escape / 暂停会取消本轮并保留纹理，可“继续准备”；存在浏览器历史时可“返回上一页”退出。退出与重新进入用独立 owner/Boot 代际，旧回调不能开启新页面。故障恢复本身无需点击。

## 实际验证

Windows、Node 22.20.0 / npm 10.9.3、Edge 143.0.3650.80。实际 E2E 构建产物，本地静态预览，软件视口。根目录运行 `node harness/loading-auto-recovery.mjs`；可用 `AUTO_LOADING_BROWSER` 指定已安装浏览器，`AUTO_LOADING_OUT` 指定输出，`AUTO_LOADING_CASE` 选单项。

- 类型检查、生产构建通过；6 文件 33 项针对性单测通过，保护平滑/单调/未就绪封顶、有限退避/低频恢复、离线与重复事件、暂停/取消、原共享请求与缓存合同。
- [report.json](report.json) 保存七个产品源码 SHA-256、浏览器版本、全部请求时间与类型、80ms 视觉采样、实际计数和场景结果；`base` 是上述基线，源码哈希对应该基线后的交付工作区。
- 11 组浏览器故障：320 慢网、390 慢网/减少动态、一次 503 后自动成功、单文件超时后自动成功、离线后自动恢复、永久 404、暂停/继续、返回上一页、取消重入/解码缓存、热缓存选角，以及超过整批截止的慢网队尾恢复。永久 404 真实等待并观察第二次低频请求，期间保持 145/146、不进入标题页。
- [320 弹层内容边界复核](bounds.json) 与主报告具有相同产品源码哈希，单独核对计数、进度、按钮以及弹层自身的水平滚动边界。320 慢网截图取自此复核，计数字符完整可见。
- 受控 Boot 停止/重入用于验证取消隔离；不创建、改写或迁移游戏存档。缓存断言区分已解码纹理与尚未解码的中断请求，也区分原有按键/触控触发的音频解锁。

## 发现与边界

首版平滑单测发现较大的首帧跳动，已调整插值时间常数后通过。取消浏览器检查曾把键盘解锁音频请求误算作图片重试，已按真实请求类型限定图片准备断言，未改音频产品代码。旧 `loading-preload.mjs` 的手动重试/文字降级场景描述旧合同，本包以新的自动恢复 harness 验证现行行为。

故障注入在应用脚本已运行后的资源准备阶段；不覆盖 HTML/主脚本尚未下载的浏览器导航错误。以上不是物理手机、真实运营商弱网、主观流畅度、听感、长局经营、线上或整体美术验收。静态 404 在服务端修复前会保持加载页并低频自动恢复，属于正确阻止缺图进入，不宣称资源最终一定可用。
