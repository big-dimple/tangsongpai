## 实际行为

- 六人浏览已有姓名、条件、次数和“下一步选路线”信息。基线浏览器实测正文/触点无相互遮挡，无依据重排，布局保留。
- 只有英雄 ID 改变才扫过 560ms、带收尖的 S 形墨痕，限定在肖像下部，不扫脸和说明区。同人重按不重播；路线预览不盖印。
- “选路线”仅确认进入下一步，不冒充开局成功。最终确认经过原有新局/覆盖提示、解锁与保存检查，保存成功后才显示 520ms 朱印。失败/取消不盖印。覆盖新局的原确认弹窗在成功保存后关闭，再呈现朱印。
- 金色收束借用现有池中 4 个节点，临时放到原前景容器，结束还原层级；没有增加粒子数量或独立更新循环。常驻预算仍为手机 32/桌面 64，30/60Hz，沿原视口分界、遮挡排除及清理机制。
- `SelectionEntryParticles` 的实际生产调用者仅选角页。`EntryDepthParticles` 还供 Loading/Boss 使用，因此本路没有改其全局行为或预算。
- 减少动态时不启动墨痕/盖印/粒子更新，原姓名选中框与朱红下划线持续提供静态反馈。重渲染、快速改选、取消、弹窗、缩放、失焦与场景退出都清理一次性反馈；中断不补播。
