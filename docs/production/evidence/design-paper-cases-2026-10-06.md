### 已得结论、保留/淘汰与未决项

纸面一致性：六组给定事件按候选规则都有唯一的手后结果；未发现必须在本手倒灌成长、跨P领奖或同场二领才能成立的情形。现行非Q与Boss边界已读源码确认。这仅是上述状态集的人工一致性通过，不是穷尽证明、实现通过或保存兼容测试。

- 保留 A 为“修复场界丢失且保留交替身份”的最小候选。②和⑤直接建立其有效性；①③证明它不能满足“所有快清成长／完全消灭拖延”，这两种宣传应淘汰。
- B 从本轮“仅修场界的最小修复”候选中退出，保留为以后重做章节成长节奏的独立方案。②⑥已显示章界与晚购差异，⑤显示章内发放时间改变；未经 b 校准不可直接替换。
- C 在“固定手型首手胜也应成长”成为明确目标时保留；否则不优先。①已经证明它改变交替身份，③证明 c<g 可能留下拖延差、c=g 也不能消除其他引擎的额外出牌收益。淘汰“有限补偿必定兼得完整交替深度与无拖延”的保证。
- 现行 O 仍可保留：没有真实局面或真人选择证明该取舍已变成不愉快必做功课。规则存在激励不等于发生率已高，也不等于净损失已确定。

未决：b/c值、上限附近行为比较、真实两分支可选牌局与分数、安全性/风险、两卡封顶时间、早晚获取概率、Boss下事件能否实际致胜，以及玩家理解与乐趣。全都未测，不从这六表推出胜率或平衡结论。下一步若获授权，应优先补③真实同手牌与逐手分数，而非先扩大成随机种子或全牌审计。

### 一、先关闭纸面语义，不锁数值

以下是设计者推荐，替代前稿相应“待决”，仍待正式选定。s 表示尚未定价的正数金币服务费，N 表示尚未选择的公开断供店数边界；不是可上线参数。

#### B 付费功能方向

1. **仅原工具候选尚未买走、且本店服务未成功使用时开放。** 买走后不补第二件；服务后买新候选仍是普通购买。理由：不暗中把单工具货架变成加购接口。反例：先买 T07 再服务补 T01，会直接扩张账本供给吞吐，不只是找方向。
2. **首稿只售“基础提升方向”，结果为一个普通版工具候选，另行买入。** 待核池限已知 T01/T10/T13，按现行使用条件过滤：T01 有可升级的已发现牌型；T10/T13 有现行规则允许的目标。不能把三者写成功能等价。只有按确认时现行使用条件过滤后仍有至少两个不同合法候选 ID，才开放服务；不按分类表原始数量判定，只剩一个也必须关闭。这里检查的是工具现行允许的使用范围内存在合法目标/可升级牌型，不能把合法售卖、牌组内存在合法目标与当前手牌可立即使用混为一谈，不保证抽到后当下手牌立即可用；实际使用仍走现行目标与阶段校验。牌组删减、复制、返场、多彩、稀有成长引擎不在本服务范围。
3. **最终最小推荐：当前商品已经属于所选方向，就不开放该方向服务。** 提示“当前已是基础提升方向，可直接购买或使用普通刷新”，不收钱后给原同 ID。玩家买的是从缺方向到有方向；不是在同方向内挑指定牌。相较之下，“排除当前 ID，只需至少一个其他合法候选”会在 T10/T13 两项池中变成指定 T13 保证；虽然少一次白花钱，仍把方向服务改成挑配方接口。因此拒绝比较中的“允许同ID”备选（PR29并未批准该行为，而是列为待决），也不选排除后仅剩一项的版本。若未来确需同方向换货，必须另立且更严格的合同，不在本稿偷加。

   **重叠分类边界：** 商品 ID→方向成员表固定、公开、随内容身份保存，不按玩家愿望临时改标签。当前 ID 只要在所选方向成员表中就禁用该方向，即使它当前无合法使用目标，也不能付费赌另一件；明确提示不能解决目标限制。若未来存在其他方向且当前 ID 不属于它，可在该方向仍有至少两个不同合法 ID 时服务一次；不能通过选择同义标签绕过禁用，也不能以一个 ID 的多个标签凑足结果数量。这里仍仅原型一个方向，不推出新分类菜单。
4. **确认时冻结合法池、当前报价和状态版本；抽样结果不提前显示。** 预览仅显示可能 ID、功能差异及各自价格。确认前状态已变则不扣钱，重新显示真实池让玩家再确认；确认后直到事务落定禁用冲突操作，不临时因库存变化重抽。首稿还要求玩家确认时有消耗品空位，并能覆盖 s 加池内最高商品售价，避免“付完服务费已不可能买任何结果”。这只保证确认当时可买；玩家之后另花钱仍可能买不起，不能自动预留/扣除商品价。反例：扣费后再过滤到单 ID，会无意形成指定保证。
5. **一次服务=扣 s、换一个工具候选、消耗本店服务机会的原子事务。** 现行工具购买效果只在之后真实购买时处理；服务不冒充工具购买或普通刷新。禁止通过误分类刷既有成长/返金。
6. **失败同候选，成功后才揭示。** 使用由本店与此次服务操作稳定确定的事务标识/结果；并发点击合并为同一操作。可靠提交前不展示候选。明确未提交则旧钱/旧货/未使用状态全部保留；结果未知先读取提交状态，不重新抽样或先退款。重试同事务得到同一候选；已成功只恢复成功状态，不再扣费。取消确认前无代价，确认后不能用取消撤销一笔已经提交的服务。若持久化设施不能保证这些结果，停止工程，不用 UI 假成功顶替。

#### C 跨店保底（与B分别比较，不叠加首发）

- 首稿只记录同一个公开“基础提升方向”，不追踪玩家隐秘最优配方。每个合格、实际进入的普通商店最多结算一次连续断供计数；刷新不增加计数，未访问商店/跳过的机会不增加。
- **“曾出现”涵盖开店及普通刷新后真实提交的该方向候选，买不起/未购买也算出现。** 每店保存这个事实；本店结束时，曾出现则归零，否则增加一次。理由：记录供给，不把不买当缺货。代价：穷玩家见到买不起的货也会失去保障进度；若这不可接受，应另定义可负担保障，不能暗改本方案。
- 当先前已结算的连续断供达到公开 N，下一个合格新店生成时，原工具位改为一个该方向的普通合法候选。不是另送一件，不自动买、不在已购空位补发。实际出现即算出现；随后普通刷新可以把它换走，玩家须在刷新确认看到会丢失当前工具。下个店的计数不能因后来刷新换走而把这次“见过”抹掉。
- 池少于两个合法 ID 或没有合法目标时，不定向发指定唯一结果；本店按正常货架进入，并说明本次保障不能兑现的原因。拟议唯一优先级：若正常货架或后续刷新曾自然出现该方向工具，店末仍按“曾出现”归零并清除待触发；若整店都未出现，则保留待触发且本店不继续累加。反例：仅剩一个合法方向工具不能由保底指定发出，但若正常随机恰好给到它，不能一边承认玩家见过、一边保留断供奖励。不能借此声称“最多 N 店必有可用功能”：严格承诺只适用于合法候选条件持续满足的场景。这是有意收窄的合同，若经常发生即否决本方案。
- 开店生成、保底候选与计数状态一起保存；失败/连点/重进复用同一开店结果。任何实现都不得先露保底再回滚换结果。

### 二、四个具体局面

#### 局面1：有20金，有空工具槽，基础牌尚待改良

公开状态：当前工具为 T15（6金）；有已发现且可升级牌型，也有合法 T10/T13 目标。玩家想增加基础强度，但没有拿到基础改良工具。三张 Joker 保持原样；没有把某个未出现的 T10 当成可买。

- **A 随机+说明：** 可买 T15、按当前显示价刷新、买其他现货或跳店。说明 T15 的实际返场作用与 T10/T13 的差别；付刷新费仍可能不来所需功能。唯一合法结果是已确认购买/刷新各发生一次；解释本身不换货。若刷新也无基础提升，缺口真实保留。
- **B 功能方向：** 若20金能覆盖 s+4，且上述合法条件成立，可支付 s 替换 T15；当前 T15 不属于该方向，池内普通 T01/T10/T13 当前基础售价均4金。结果保存后只揭示其中一件；玩家再决定花4买、留钱或正常刷新。唯一合法结果是余额20−s、一个已保存候选、服务机会已用；不预扣4、不保证 T10。若20不足 s+4则服务不开放，不能为演示假设费用。
- **C 保底：** 若此前未达 N，当前 T15 不自动变货，选择仍与A一致；店末未见基础提升才计一次。若已达 N 且合法，则开店原工具位本就应为池内一件，不会仍显示 T15 再额外弹奖励。玩家付正常4金购买或放弃，无服务费；代价是之前已等待以及失去本店原随机工具机会。
- **对症反例：** 若真正缺的是 T02 删牌，B/C 的基础提升池均不解决。此局面不能被标成“已修复改牌供给”，需要另证删牌功能方案，不能悄悄扩池。

#### 局面2：只有4金，下一关有压力

公开状态：当前工具 T10 售价4，有合法目标和空槽；下一关目标与限制已可查看，但不预测当前构筑能得多少分。当前仅够买一件基础工具；服务费 s>0。

- **A：** 可花4买当前 T10 做即时改良，或留4不花；也可按展示费用刷新，但可能再也买不起抽到的工具。说明只帮助比较即时收益、现金和风险。唯一合法购买结果是0金并获得T10，不声称能过下一关。
- **B：** 当前 T10 已属于所选方向，因此该方向服务本就禁用；另外4<s+4也不满足预算门槛。解释“已有该方向工具”并显示现货购买入口，不能装作需先付服务费才能获得它。不把“仅够投资一次”的玩家引向付费看货后买不起。当前T10仍可买；不能自动借款、降价或送货。反例：若只检查够付 s，玩家可能花完寻找预算却失去已有可用工具。
- **C：** 本店已出现 T10，店末断供记录归零，即使玩家选择不买；不能靠故意放弃把下次保底养出来。若本店开场已触发保底，它只保证基础方向，其中T01/T13未必比T10适合当前压力；玩家仍要选择。压力不会暗改保底结果。

#### 局面3：原工具已买走，工具位显示已售

公开状态：玩家已经成功买走原工具，有剩余金币。不能把“已售”视作随机断供。

- **A：** 不新增说明性补货。是否通过普通刷新得到新工具严格沿用当前真实刷新规则与费用，不能把本稿当作禁止或授权新的刷新行为；一次已支付的普通刷新不得重复免费执行。
- **B：** 服务本店关闭，即使有钱、工具已用掉或后来普通刷新重新出现候选也不恢复“尚未买走”资格。本店“曾购买工具”事实与服务使用事实分别保存。理由：避免买→刷新→服务绕回新增定向供给；这是B自己的边界，不改A的普通刷新规则。
- **C：** 不因空位中途触发保底或退还进度。若已买走的是基础方向，记录曾出现并在店末归零；若是其他方向且整店未见基础方向，离店时只计一次缺功能。玩家购买其他工具不等于拿到了基础提升，但也不会获赠第二件。
- **唯一合法结果：** 已有购买保持一次已完成；服务/保底都不补空位。反例：已售后把“候选不存在”解释为立刻保底，会诱导每店买空领奖。

#### 局面4：付款后保存失败，玩家连续点击

公开状态：操作前20金，玩家已经确认一笔付费服务或正常购买/刷新；界面尚未显示成功。不能根据一个报错字样判断持久化事务一定未提交；这里按现有本地 IndexedDB 保存语境，不引入游戏服务端。

- **A：** 当前普通购买/刷新仍是一笔事务一次结果。明确未提交则保留旧钱旧货；提交结果未知则先核状态；已提交恢复已存结果。连点不成为多次购买或免费刷新。信息说明无附带状态变更。
- **B：** 明确未提交：仍20金、旧候选、服务未用，且不展示新抽样；重试复用同一候选。已提交但回复失败：恢复20−s、新候选及服务已用，只揭示一次；不再次扣 s。结果未知：锁冲突操作、查询，不另抽、不先退款。后续商品购买是另一笔显式事务，失败不能回滚已成功的服务。
- **C：** 若失败发生在保底开店，则在开店候选和计数整体恢复前不显示可买货架，重试还是同店同结果；若发生在之后购买，则只恢复该笔购买，保底出现事实不因购买失败清零/重抽。连点不增加断供店数。
- **唯一合法结果：** 每个事务最终只能“完整旧状态”或“一次完整新状态”，不允许扣钱无货、货出现未扣钱、重试换结果或计数重复。若长期无法确定结果，应保留错误/重试入口而非宣称成功。

### 三、纸面结论与下一道门槛

对“同 ID 白花服务费”的进一步质疑成立：此次纸面最终推荐已改为当前属于所选方向就不收费、不开放该服务，“允许同ID”备选不再推荐，PR29相应待决在本稿收敛为纸面推荐。B 仍是优先比较项，但它解决的范围仅是基础提升方向；T02/a06/S02 等缺件没有被顺带解决。A成本最低，C能约束特定功能的断供尾部，却引入跨店状态和等待代价。四局面没有产生自然胜率、通关或一亿可达证明。

在真正开工前，仅需进一步锁：是否采用上述服务/保底推荐、合法池与当前工具规则逐项核对、s/N及结果权重的平衡试验入口、新内容身份、原子保存能力及窄屏完整密度。这里已经给出候选行为，不把尚未定价或未实现保存机制伪装成已验收。
