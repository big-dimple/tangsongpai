## 已证实原因及准确位置

1. **弹层空白属于调用与布局的组合。** `src/game/GameScene.ts:1112–1115` 的阿默候选传给 `DetailDialog.open` 第三参普通 actions，只有一句正文，没有 choices/cards，也未挂 `hero-skill-dialog`。`src/game/DetailDialog.ts:61–63,171–180` 将普通 actions 放 footer，choices 才放正文；`src/style.css:265` 统一固定近全屏高度。实际 PC 弹层 880×744，正文仅27px高，首个候选 y695；手机352×716，正文25.5px，首个候选 y565。所有候选都在 footer、正文 choices=0。其他五位实际打开的操作都在正文 choices，并有 hero-skill-dialog。
2. **快捷候选没有默认最佳收益。** `src/game/AssistSelection.ts:8–17` 在同点数枚举中先 offer 对子，再 offer 三条；`GameScene.ts:860–901` 直接分页，`1112–1115` 直接生成弹层按钮，没有评分/排序。PC第一屏只给一个对子，手机第一屏给对子和三条；实际点第一组均草拟 Q♠Q♥，再点同组取消。`AI 主手`只选主手，文案明确“助攻自己选”，没有自动助攻。能证实顺序和所点组；不声称当前代码有自动选对子算法。
3. **竖屏阿默信息丢失。** `GameScene.ts:404` 隐藏 roleText；`405–407` 只恢复其余五人。`973–981` 虽更新阿默文案和可用色，仍不可见。实测阿默 `阿默·出前选助攻` visible=false；其余五位对应标签均 visible=true。不能直接把阿默加入原恢复分支而保留姓名原位置：`391` 姓名显示判定也只排除五人，需同时避让姓名/目标/金钱。
4. **提醒已有但弱、位置割裂。** `GameScene.ts:384–388,977–981,1108`：头像30px/44px，外框34px/48px，可用从1px变2px并4秒呼吸；双端各253帧采样 alpha约0.700002–0.999998。该提醒基于 opportunity，未凑组时也可能为 needs-selection，不能当作“现在可以立即执行”。`HeroActionShortcut.ts:4–6` 快捷按钮宽44、此夹具高56；PC x557/y680，手机 x12/y652，靠边但没有低于44px的命中缺陷。快捷按钮 alpha始终1、只有通用启用状态，无头像同等级可用提醒。阿默还已有“本场助攻1/1·4组”的牌桌提示，不应写成完全没有提示。

## 完整最终分：三条不总是最高

主手始终 9♠9♥K♣K♦（两对、H=103、基础 M=2），余牌 Q♠Q♥Q♣6♣。当前真实规则域验证主副手互斥；副组会消耗并排除出 held，不能先算留手收益再无条件乘 ×4。每个候选独立用同一初态领域命令算最终分，公开 `previewR2Hand` 最小/最大也都等于下表。普通及留手反例四种副组都比较；其中第一对子和三条各在双端实际出牌验证，共八笔保存。

| 副组/消耗 | 普通配置 | 留手反例：d01候场席+d08留声机、Q♣留声纸 | 再加 b03增长倍率1.5 |
|---|---:|---:|---:|
| 不助攻（对照） | 206 | 556 | 710 |
| Q♠Q♥（保留Q♣）×2 | 412 | **865** | 1174 |
| Q♠Q♥Q♣ ×4 | **824** | 824 | **1442** |
| Q♠Q♣ ×2 | 412 | 515 | 824 |
| Q♥Q♣ ×2 | 412 | 515 | 824 |

留手反例第一对子：M依次 `2 + 1（Q♣留声纸）+ 1/2（d01）`，再 `×6/5（d08）`，最后阿默 `×2`，最终 `floor(103×42/5)=865`。三条吃掉 Q♣，三项留手收益全消失，`floor(103×2×4)=824`。副组不加主手热度；实际 sets 中 scoringIds 只有四张主手，heldIds 对子为Q♣6♣、三条仅6♣。

第三配置仅评分器受控对照，未额外做原生出牌：b03在 jokerScore 加1.5后，阿默助攻再乘整个倍率。对子 `M=(4.2+1.5)×2=11.4` →1174，三条 `(2+1.5)×4=14` →1442；实际 event index 中阿默分别9/6，最后 Joker分别8/5。当前 `scoreR2.ts:363–364,381–384` 的留手→Joker→阿默时点不可改变，不能借其他英雄的乘法时点替代。
