## 首页变化与边界

正式首页复用现有加载页 `.load-scene` / `.load-top` 的实际 DOM 模板、内联 SVG、山峦、日印、开卷章、三牌花色和共享排版。旧 Phaser 粗三牌及压扁弹跳标题绘制已移除，不新增图片、imagegen 或网络资源。新组件在模块加载时保存原加载页模板，在首页退出时移除自身 DOM 和监听；首页样式全部以专属类限定，不修改加载控制器或加载页 HTML/CSS。

有存档时显示真实英雄、友好模式名、章数与金币，“继续本局”和“开始新局”各自保留原路由与存档条件；普通模式不再展示 D0。按钮改为原生 button，支持键盘/读屏与至少 44px 的命中区域。原模式分区、覆盖确认、保存/恢复、音频路由及防双击窗口保持。现有 harness 的入口定位兼容原生按钮，计分与结算代码未改。
