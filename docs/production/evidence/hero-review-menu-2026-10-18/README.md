- [r2RouteGrowth](../../../../src/domain/r2RouteGrowth.ts)的`r2RouteFamilies`按**实际主手牌型**分类，`settleR2RouteGrowth`分别累计本场实际打出过的家族；没有按初选路线隔离。当前bounded规则从实际符合的家族里只取最大一次，同值按G/S/F既定次序，规则原样。
- 因而选了同花路线后打对子，出现G来源可以正确；普通同花只读F。没有取得线上1000分那一手的完整trace，不能仅凭截图判定具体来源算错。本批只将前台名称简为“过关加成”，正文说明实际对应牌型与次数。
