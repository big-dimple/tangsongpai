## 六人比较口径

| 英雄 | 一场的真实能力及条件 | 主要代价与独立价值 |
|---|---|---|
| 苏轼 | 一次×3，任何合法主手、有余牌即可 | 即时救场；弃尽余牌、失去本手留手收益与保留好牌机会 |
| 花蕊 | 一次5/10/20金→×1.5/2/3，两对及以上 | 留手不丢；金币减少会损失持币加成和利息；另有至多2金关末息 |
| 秦琼 | 一次真实弃补押下一手，新牌进有效核心且命中才×2，否则×0.85；未押手×1.15 | 付弃牌成本且押后锁定；有常态收益，不能把成功分支当必得倍率 |
| 辛弃疾 | 一次照付弃牌成本、多看最多2张候选，自己留应补数 | 不直接乘分；提高选到成型牌的机会，未留候选本场不再抽；静场仍可用 |
| 刘娥 | 一次对子以上，将一张有效核心首次普通点数从H转入M | 失去同值热度；A11、JQK10、数字按点数，0点不能用；低M时收益可能超过苏轼 |
| 文成公主 | 合格手蓄1层，换型最多3层，有层可释放×1.5/2.5/4；可重蓄 | ×4最早第四次出牌；释放手不蓄，重复未放或高牌/对子清空，场间清空 |

普通D0基础4次出牌。理想化“每手普通分相同B、无后置加倍率及留手差异”下，苏轼四手容量从7B降至6B；花蕊最高档也是6B但付20金；秦琼一次押成加三次普通为5.45B，押败为4.3B；文成三手铺垫后第四手释放路径为7B（实际是三层×4），两次一层释放为5B。此归一化只是预算解释，不是实际四手总分公式或自然胜率；秦琼普通×1.15在整手加倍率前发生，实际组合不能一概把整手结果乘1.15。

刘娥简单无后续效果时为`(H−p)(M+p)`，收益取决于H/M，不能拿“+10倍率”直接当×10。辛弃疾是选牌质量：仅在“44张未见牌中恰有3张有效牌、补1张”的条件模型里，普通1张命中约6.8%，看3选1约19.5%；这不是通关率，也不是所有实际牌堆都满足该条件。
