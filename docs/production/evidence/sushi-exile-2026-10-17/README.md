## 批准规则与实现边界

**贬谪：出牌时，弃掉手里剩下的牌，这一手得分变为4倍。每场限用1次。** 至少还要有1张余牌；普通对子和高牌也能用，不要求余牌同点。

- 选用与取消只改未保存草稿。正式 `PlayHand` 在一个事务中消费全部可见余牌、正常计算主手、使用本场次数并保存；保存失败可原候选重试，重复收据不再计分或消耗。
- 余牌进入普通弃牌区，不算主手或留手，不触发普通 `DiscardHand` 收益，不额外花普通弃牌/出牌次数或金币。之后沿既有牌堆正常补牌；牌堆耗尽依原规则处理，下一场正常复原洗牌。没有永久删牌、手位占用或追加惩罚。
- 全部正常主手/唐宋牌/版次/过关加成完成后，先将正常得分向下取整，再把这个整数×4。例：922.5先得到922，再得到3688。真实独立 `amo.exile` 角色来源把倍率×4，trace额外保留整数前后分；结算直接显示保存的整数×4。
- B08静场及Q01禁用角色能力时不能选用；成功提交前不花次数。每场首次入场重置。旧单张×3、旧助攻局和同局重试保留原内容身份，不迁移；其余五人新局身份不变。
- 新身份 `quality-r2-amo-exile-v1`，规则哈希由继承S04的批准合同生成；外角色冒用身份、伪造余牌分区/次数/倍率事件/整数得分均由导入校验拒绝。
