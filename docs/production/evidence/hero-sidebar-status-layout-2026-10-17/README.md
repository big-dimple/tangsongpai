基线 main：`4b0de064480a9c518f6443984ef6a465c4b3323d`。分支：`fix/hero-sidebar-status-layout-20261017`。本包独立于辛弃疾弃牌修复 `2f2eb708`，不改写该提交。

PC 原因是角色状态只分得头像右侧窄宽度，换行后仍与固定坐标的场次标题共用高度。现将状态放到头像下方，给全宽两行独立区域，在原 250px 左栏内重新安排场次、热度、目标、金币及进度；PC 字体保持 14px、scale 1。移动端保持 13px、scale 1，长状态缩成保留层数/倍率/支付/目标的短句，例如 `蓄1层 · ×1.5`，不再只剩技能名。按钮命中区域同步状态带；长规则仍点英雄查看。

## 文成规则结论

**同牌型主动释放不会永久停用。** `r2AzaoCharge.azaoChargeStep` 对合法释放先按既有层数计入 ×1.5／2.5／4，然后清空层数和前一合格牌型；没有本场已用或永久禁用字段。本场未结束时可以再次蓄势；同牌型“不释放”才清空，合格时仍可释放。

根自然局已计入 ×1.5 后却显示停用，是表现适配错误：`azaoChoice.enabled` 原先还要求 `phase === await-input`。真实命令先保存胜利结果，演出时 run 已是 `stage-cleared`，因此被误当成能力停用。

本包将能力启用与当前能否操作分开。结束后不可再提交操作，但显示“本场结束”；真实已用状态保留“已用”，B08／Q01 在可操作场次仍显示真正停用。刘娥、花蕊的展示适配存在同一阶段混用，已一并分开。没有更改领域规则、抽牌、概率、次数或存档。
