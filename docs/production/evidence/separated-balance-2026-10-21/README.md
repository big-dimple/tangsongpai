## A：只抬第二、三场至800/1200

O、A各18条都过了前三场，没有观察到低成牌死亡。A总出牌80→94、弃牌8→10；54场中首手过关30→27。不能由“全过”证明没有死局，也不能由多14手证明有趣。

真实新增取舍的例子是 `A-azao-02` 第三场：O第二手继续两对已过800，A为交替合格牌型弃牌，随后自然补成葫芦，总2920/1200。**平凡补分也存在**：辛/文03第二场原370+400=770，A再出一张高牌30便到800；多这一手主要少拿1金，不能称更深决策。

花蕊须特别区分策略误判。`A-xiemu-01` 第二场普通两对194，固定策略用“当前分×余手数”评估194×4<800，提前烧10金成582；后来正常同花724。O不烧火也以194+724=918过600，按已发生同一出牌算术也超过800。**这10金不是客观被目标强迫支付**，是保守策略的机会成本；不能拿它证明花蕊必弱。A03最终同为18金，却少买了满堂彩/少升型，余额相同也不表示经营没有受损。

结论：A给苏/秦/辛增加较多手数，给花蕊增加用钱压力；本样本未造成死亡，仍有被经济与低成牌拖累的风险未覆盖。现在证据更像增加补分与资源税，尚不足建议正式采用400/800/1200。

## B：只把刘娥普通转换改为p/2

与同3条O逐链配对：首场分数 **688/704/2028→688/704/1183**，首场首手过关仍3/3。前两个种子的自然起手是强顺子，普通手已能过关，根本没用刘技能；所以这两条也说明目标偏轻不全是刘娥造成。

前三场合计首手过关9/9→8/9，总出牌9→10。03第二场从4点目标的一手774，变为516再补普通对子290，总806/600；其他两条命令完全不变。B降低了溢出收益并出现一次真实补手，但**没有在这3种子中降低首场首杀**。

技能仍有明确价值：裸8对子102→O430/B258；已有4金满堂彩时282→O1330/B798，B仍远超400。2/2/A/A纸面无技能182→O1040/B600，A点数严格为+5.5倍率。普通目标那一次不加热度，增强与重触原样、每手最多一次/每场2次；不是把最终得分简单砍半。

仅在无其他相依钩子的静态算式中，B为 `(H-p)×(M+p/2)`。它在原倍率低时很强，倍率高时相对收益变小甚至不如保留普通点；前三场不能直接推出后期价值。B比统一抬目标更直接作用刘娥的溢出，但还未证明“首杀降低且仍好玩”。

## 成长是否仍值得买

付费升型在O/A/B都产生实际增益。例如O辛03第二场两手370+400=770，去掉已买等级的**同手局部算术**为266+290=556，原600就不能在同样两手内完成；成长不是抬到800后才有价值。A同路径再补30为800，去等级为586，也说明经营影响节奏。

不过没有无购买策略对照，不能断言“不买必死”或“每店必买”。自然货架未买到b10/b03/c04/c06，累计唐宋牌成长正读取为0；付费升型O30、A28次，差的两次都在花蕊。实际trace保留每次成长读取与结算新增；路线成长仍处前三次宽限，新增不回灌本手。**累计成长牌的必要性、跨章经营仍未回答，不靠新种子补成功。**

## 覆盖不足与下一步

- 固定成组入口、单一近视策略、每人3种子。前两个种子强顺子开场，样本偏轻；不能推总体胜率、英雄公正排名或长期乐趣。
- 秦策略只在需弃且保留对子、至少换3张时押合法两对，这批没有满足并实际押注；文成有蓄1/2层，却在释放前过关或被不合格牌清空。不能把其主动当作已公平测足。纸面补充独立验证秦普通×1.15/新牌进核心押中×2/错×.85；文成交替0→1→2→3及释放×1.5/2.5/4，**这些不是自然链命中率**。
- 同seed不强制后续同牌。实际这21组配对的三场起手和已见货架均相同；`A-azao-02` 同场第二次出牌前因新增弃牌出现不同手牌。额外出牌、烧钱、升型取消等后续变化都按整条决策链解释；索引中的summary逐对标出首个命令/分数/可对齐手牌差异。
- 后续若另获授权，优先真人审B是否保留选择和爽感，并补秦押型、文成释放、花蕊保留钱的决策质量；A先看是否只是补分税。**这次停止在39条，不扩大样本、不落实正式数值。**
