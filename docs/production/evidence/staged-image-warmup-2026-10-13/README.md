原 Boot 在标题出现前阻塞加载全部12张英雄头像/选角图；选角高清走独立 Phaser loader 且未设置单文件超时，牌桌入场另等高清与 J/Q/K。丑牌缩略图现有瞬时失败重试、机制图兜底，详情4件/2并发缓存和重试，以及商店图片局部刷新已存在，保持复用。

现 Boot 只保留原轻量纸桌队列。标题可操作后后台预热12张英雄预览和3张路线起手牌缩略；选中英雄高清优先，商店预热下一牌桌 J/Q/K 和当前英雄。只有已选英雄高清进入预热，丑牌高清仍按原详情按需接口加载，不扩为全套高清队列。

固定24键（12预览+6英雄高清+3起手+3宫廷），2并发，每次传输/正文/解码共用4500ms截止；流式正文最多128KiB、解码60万像素，复用实际 Phaser 纹理，不另持久存档/无限缓存。HTTP 404/其它确定4xx不自动重试，网络/408/429/5xx最多自动重试一次；失败后姓名首字或原机制图仍可操作，独立简图提示及44px重试按钮可恢复。省流/2g不预热三张推测起手图。进度仅在标题/选角/商店显示，牌桌隐藏，避免覆盖操作提示。

图片到达只换图片容器，保留选角按下的操作目标。选角布局、结算布局、评分域、存档身份、当前保存刷新、音频、素材不改。未新增音乐/音效，未清空用户存档；浏览器用各自隔离测试上下文。
