## 统一口径（建议采纳，未设新阈值）

每笔比较冻结 `SHA + contentVersion/hash + 阶段 + 公开牌组/有效ID + 牌型等级 + 金币/券/折扣 + 槽序/指定卖或献对象 + 已有成长/版次/计数 + 资历 + Boss/封禁`。本次六英雄中仅用老幻作无主动干扰的纯评估载体，三路线身份均为 `quality-r2-core-build-v1 / json-fnv-v1:6dfe1a721e4949e6`，牌型Lv1、族资格0。章节1／3／8输入通过不变量，但中晚期是显式投影，没有真实获得／成长历史。

1. **同一窗口和基线。** 先列保留／不买，再列直接买、指定售后买、已有工具使用／保留。即时为第1个给定手，限次为剩余合法出牌，长期为明确列出的给定序列；不把剩余场次当触发次数。为成长拖延多打的手须另计出牌／安全成本，不能自动延长窗口。示例 `n=1/4/5` 仅是相同固定牌面条件序列，第5次重置出牌预算，未发牌／结算／赚清场奖励，不证明能实际活到第五手。
2. **现金与非现金成本并列。** 现金净支出 `P + U − R`：P取指定售后实际优惠价，U为实际使用费，R仅已发生退款／返金；未出售的未来残值未知。已有牌购价属沉没投入，不重复扣钱，仍记失去本体／成长／版次、协同来源及槽位。S07献牌不是出售，R=0且不触发出售成长。利息／后续采购／永久资源／一店额度分别列账；不擅加权折成金币或“总回本”。当前利息档不能写成未来稳定收入。
3. **寿命区分消费与兑现。** f06新购余4，已有余 `4−handsScored`；第4手本体有效，手后销毁，跨场不重置，封禁手照样消费。已知有效兑现数最多为这些消费手中未封禁且条件成立的次数；未来不知道打几手就写未知。永久效果无固定4次上限，但只在实际存在的后续窗口读收益，死亡／终局／再替换后的收益不计入已知值。
4. **收益保单位与时点。** 每手调用权威 scorer，记H/M、来源事件和最终 floor；条件累计 `D(n)=Σ(score_change(i)−score_keep(i))`，先各手 floor 再相减。成长先读旧值、手后长、下手生效；替换和献牌须重建保留来源／槽序，不能总分除卡。分数、资源和概率不相加；单手增分不直接推出省手、过关、胜率或购买价值。
5. **前置和当局适配。** 区分公开牌组存在见证、当前公开手能执行、来源已持有／未封禁、本手实际触发；路线标签与上手记录都不替新牌保证未来触发。真钱足够与购后效果门槛也分开。未知未来抽牌／商店／寿命概率保留未知；不得因缺一个类型、拥有搭档、晚期或稀有度补星。

**可复算的估寿命约束：** 给定后续n次合法出牌时，f06最多消费 `min(n,4−已用)` 次，有效兑现还要扣其中封禁手；不能承诺全部兑现。对b03／c04／c06，步长／上限为0.25／3、10／100、0.5／6；第i手读取 `min(cap,g0+step×此前实际合格成长次数)`，全此前手都合格仅给条件上界 `min(cap,g0+step×(i−1))`。最后一手新长的值在窗口内不兑现。已有永久效果的明确下界只取当前给定能触发的手，往后没有已知手序就没有可报告的总寿命收益；不能拿“永久”当无限收益。S03／S04每个已知后续场均承受资源减少，S07所献来源每个实际后续手的损失由同输入scorer比较；这些都与新效果并列，不被一次高分抹去。
