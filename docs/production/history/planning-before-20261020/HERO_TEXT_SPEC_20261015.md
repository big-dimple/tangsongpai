花蕊夫人尤其不能把戏曲剧情当生平：清编《十国春秋》卷50将后蜀慧妃记为徐氏，并辨析多个同号；教育部辞典另列费姓及前/后蜀人物，又单列戏曲剧情。这里保留称号与女诗人意象，不裁定姓氏/年龄/死因。“执剑凌风”为用户主题，不追加历史女将、复仇刺杀或神格。文成公主的神迹、秦琼门神与刘娥狸猫故事如未来使用，必须明确“传说”或“游戏演绎”，不得混成事实。

资料核对日期2026-10-15；未照抄长段史料。苏轼“余音袅袅，不绝如缕”出自[《前赤壁赋》](https://zh.wikisource.org/wiki/前赤壁賦)，原文是客人箫声；辛弃疾“众里寻他千百度”出自[《青玉案·元夕》](https://zh.wikisource.org/wiki/青玉案_(辛棄疾))，主题仍保留用户指定的《破阵子》剑意。秦琼据[《旧唐书》卷68](https://zh.wikisource.org/wiki/舊唐書/卷68)“跃马负枪而进”的冲阵事迹，技能仍是弃牌押下一手，不改成保命。刘娥据《宋史》卷242垂帘决事；文成公主取故宫条目的入蕃和亲，不引用金城公主“和同一家”。花蕊夫人“赏赐”取[传世宫词](https://zh.wikisource.org/wiki/花蕊夫人宮詞)“库中先散与金钱”“月头支给买花钱”，作者归属有争议，不钉死为某人亲作；宫廷意象不取消10/20/30金成本、×2/3/4与关末利息。其余四句宣言均为游戏演绎。
