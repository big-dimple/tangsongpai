# 首章真人观察（待开展，不能预填PASS）

记录版本、设备/尺寸、是否初次体验。先不由观察者告知答案，正常产品提示可出现并如实记录；观察：

1. 能否自行找到想试的成组、顺子或同花路线，并说出当前牌还缺什么。
2. 能否指出想保留/尝试换掉的牌；知道参考不是必选、换牌不保证补齐。
3. 有工具时，能否找到工具包、选目标、说明变化并自行取消或确认；无工具时能否找到购买路径。
4. 能否指出自己的选择促成了哪项积攒，随后自主决定继续、换方向或停止。

每项只记原话、实际操作、遇到的阻碍及给予的帮助；未观察记NOT_RUN。脚本通关不填人测PASS，不虚构留存率，不要求重审长计划。

当前统一首章候选另记录前120秒实际顺序、首次情境提示是否帮助自己操作，以及普通/跳过/不再显示/老存档情况。先商店后战斗，不要求每人120秒相同节点或分数；观察产品内提示与观察者额外帮助分开。必要引导已有工程候选，见[统一证据](evidence/w6-shop-guide-2026-10-08/README.md)；真人普通/跳过/不再显示/旧局理解仍NOT_RUN，C04完整图鉴/历史按旧范围暂停。
