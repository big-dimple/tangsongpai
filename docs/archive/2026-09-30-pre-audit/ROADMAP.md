# 唐宋牌 Roadmap

## 当前目标：Playable MVP

玩家先从六名“唐宋”中选择自己的舞台身份，再通过唐宋牌构筑、关卡和商店完成一整局。

### Phase 0 — 工程与规则骨架
- [x] Phaser 3 + TypeScript + Vite
- [x] 六唐宋角色选择
- [x] 六种可实际生效的角色被动
- [x] Seeded RNG
- [x] 52 张标准牌与洗牌
- [x] 9 类标准牌型识别
- [x] 基础计分
- [x] EffectQueue
- [x] TriggerEngine
- [x] 浏览器合成基础音效
- [x] 单场演出闭环

### Phase 1 — 唐宋牌
- [x] 5 张机制明显不同的唐宋牌
- [x] JSON 数据驱动 Joker 定义
- [x] Joker 逐张触发演出
- [x] 分数来源明细
- [x] Joker 规则与叠加单元测试
- [x] 六角色正式立绘接入（BootScene 预加载 + 选择界面 3×2 卡片 + HUD 角色区）

### Phase 2 — 完整一局
- [x] 3 个普通关卡（RunState / StageDefinition + 逐级目标 700/1500/2200 + 过场流转，Batch 2A，目标经 2B 仿真校准）
- [ ] 1 个 Boss
- [x] 金币与商店（Batch 2B）
- [x] 唐宋牌购买 / 装备槽（Batch 2B）
- [ ] 一局胜负结算
- [ ] 角色专属开场台词与胜负台词

### P0 — 3D 视觉资产母版包 v1（素材交付完成，游戏接入另开批次）
- [x] S 级：可变形双面扑克母版、五档唐宋牌卡框、三套 PBR 源通道与预览
- [x] A 级：11 个东方道具、8 个爆分字、11 条卡牌动画、12 个舞台组件
- [x] B 级：1920×1080 三层背景、3 套透明特效 atlas、6 张 512×512 头像
- [x] Blender 无头自驱源脚本、逐文件用途清单与 GLB/纹理/体积校验

### Phase 3 — 东方舞台与爽感升级
- [ ] 六角色正式东方立绘与入场演出
- [ ] 明亮东方戏台 UI（朱红、玉色、鎏金、米白），避免西式暗黑赌场风
- [ ] 连锁音高系统
- [ ] Stem Music / 动态音乐
- [ ] 屏幕震动分级
- [ ] 粒子预算
- [ ] 稀有卡动态材质

## MVP 验收线

玩家打开网页后选择角色，完成多关演出，在商店调整唐宋牌构筑，挑战 Boss 并得到明确结算。手机与 PC 都应能顺畅完成主循环。
